# Get Started with Spec-Driven Development

A ready-to-use GitHub Codespace for the [GitHub Dev Kit lab](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_configure_github_dev_kit_lab.html)
on spec-driven development with GitHub Copilot.

## What's included

Opening this repo in a Codespace gives you a fully configured environment with:

- **Git 2.48+**, **.NET SDK 10**, **Python 3.12+**
- **uv** package manager and **specify-cli** (GitHub Spec Kit)
- **GitHub Copilot** and **GitHub Copilot Chat** extensions
- **SQL Server 2022** running in Docker on `localhost:1433` (user: `sa`,
  password: `LabPassw0rd!2026`)
- **SQLite** as a lightweight alternative

## Getting started

Click **Code → Codespaces → Create codespace** — the environment is pre-built
and ready in seconds.

> Requires a GitHub account with GitHub Copilot enabled.
